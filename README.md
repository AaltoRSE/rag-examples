# rag-examples

This repository contains examples for RAG (retrieval assisted generation) setups.

## Available examples

### Data Ingestion

- langchain-pdf-ingestion - An example script that demonstrates and tests different
  PDF loaders provided by LangChain. See
  [README](./data-ingestion/langchain-pdf-ingestion/README.md) for more information.

### Serving

- langserve-rag-api - An API endpoint that serves LLMs and RAG endpoints using
  langserve. See [README](./serving/langserve-rag-api/README.md) for more information.

## Contributing

We gladly accept new examples to the repository.

If you have existing examples related to RAG setups and would like to contribute
them, please check out [our contribution guide](./CONTRIBUTING.md).
